DECISIONS AND TRADEOFFS
- Scrapy, no browser (Selenium/Playwright): the site is server-rendered, curl returns the products.
  Tradeoff: the 4 "Build-your-own sets" have no price and no image, because JavaScript builds them.
  A browser for 4 rows was not worth the complexity.
- HTML scraping instead of /products.json: the task is about scraping. Tradeoff: more selectors to
  maintain, and a change in the page layout can break them.
- Data sources: product data embedded in the page (SDG.Data.productJson: IDs, category, variants, stock),
  #description-item for the description, the variant picker for prices. Rejected the page metadata
  (microdata / ld+json) and the tracking "var item": unreliable (wrong currency, default variant only).
- One self-contained folder and spider per task: easy to review and run task by task.
  Tradeoff: some code is duplicated on purpose.
- Sets: one row per set, set_variant_ids holds the variant IDs per slot. Build-your-own sets keep the
  discount % instead of a calculated price. Tradeoff: BI has to calculate the price, with small rounding
  differences, but no information is lost. The "Save N%" badge is not used: it is rounded.
- Price split into price (regular) and discounted_price (only when on sale), kept as text with the
  currency symbol, as shown on the site.
- All CSV values are quoted strings, so IDs are not changed by Excel (e.g. 8.94E+12) and types are not guessed.
- Politeness: robots.txt obeyed, 1 second delay, one request at a time, in order (rows keep the site's order).
  Tradeoff: a run takes about 2 minutes instead of seconds.
- Country chosen by commenting a URL line instead of a setting or proxy: simple and explicit.
  Tradeoff: switching countries is a manual step.

KNOWN LIMITATIONS
- US price format is mixed: $116.00 (variant picker) vs $116 (button).
- Empty descriptions: Ultralip Duo (no description element), Digital Gift Card (US only).
- 4 empty images: the build-your-own sets (see above). Images are one photo per product, not per shade/variant.
- Category is Shopify's product type: internal names (Merch = "Glossier Goods"), sets take their contents' type.
- The ToS prohibits bots; robots.txt allows product and collection pages. Low volume, training purpose.
